Project: Weather App

1. Features we will build
- Search weather by city name.
- Display temperature in °C.
- Show weather conditions, such as sunny, cloudy, or rainy.
- Display humidity and wind speed.
- Handle invalid city names and API errors.
- Show a loading message while fetching data.

2. Technologies
Technology	Purpose
HTML	Create the page structure
CSS	Design the weather interface
JavaScript	Handle search and display results
fetch()	Get weather data from an API
JSON	Read the API response


3. Create these project files

Create a folder named Weather-App in VS Code.
Weather-App/

index.html --> Structure

style.css --> Design

script.js --> API logic

README.md


5. How the app will work
Enter a city name
JavaScript fetch()

Receive JSON weather data
Display weather on the page
