# Weather App 🌦️

A simple Weather App built using HTML, CSS, and JavaScript. It uses the OpenWeather API to fetch and display real-time weather information for a searched city.

## Features

- Search weather by city name
- Display temperature in Celsius
- Show weather conditions and icons
- Display humidity and wind speed
- Handle empty input and invalid city errors
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## Project Structure

```text
Weather-App/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Add your OpenWeather API key in `script.js`.
4. Open `index.html` in your browser.
5. Enter a city name and click the Search button.

## API Used

This project uses the [OpenWeather Current Weather API](https://openweathermap.org/current) to retrieve weather information.
